## 👋 About Me

I'm a **Junior Web Developer with 6+ years of professional experience in graphic and UI design**, based in Jashore, Bangladesh.

I started as a designer, working with restaurants, brands, and agencies, and moved into development to build the products I used to design. Today I build full-stack web applications with **TypeScript, React, Next.js, Node.js, Express, and MongoDB**, with a growing focus on PostgreSQL and authentication.

My design background shapes how I code: I care about **visual hierarchy, typography, spacing, and accessibility**, and I want the interfaces I build to be responsive, maintainable, and genuinely useful.

> **Design thinking + development skills = better digital experiences.**
